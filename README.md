# Countdown Banner — Prototip

Kampanya bitişine kalan süreyi gösteren yatay banner'ın çalışan prototipi. Bağımlılığı yoktur; `index.html` dosyasını tarayıcıda açmak yeterlidir.

- **Genişlik:** Desktop 1500 / 1280 / 960, Mobil 430 / 320 veya pencereye göre otomatik.
- **Senaryo:** canlı geri sayım, sabit durum (02:14:45:20), son 10 saniye.
- Gerçek bir bitiş tarihi için: `index.html?end=2026-11-20T23:59:59%2B03:00`

Sarı çerçeveler sabittir; süre boyunca değişmez.

Bileşenin CSS, HTML ve JS kısımları `index.html` içinde yorumlarla demo sayfasından ayrılmıştır. Arka plan ikonu: `alarm.svg`.
